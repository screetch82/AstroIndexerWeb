Changelog

Everything new, improved, and fixed across AstroIndexer releases.

1.0 Release Candidate 2

July 24, 2026

Another step toward the full 1.0 release. RC2 tunes what RC1 introduced rather than adding new tools — stability, clearer workflow behavior, stacking reliability, and issues reported through user feedback. Existing installations keep working; if you have been running several beta or release-candidate builds, temporarily moving aside your AstroIndexer user folder before first launch gives the cleanest test. Improving migration from older user folders is a main focus for RC3.

Improvements

  • Improved Stacking and external-tool handoff — Autopilot and the Stacking Queue now show a clear preview before Siril or PixInsight launches, including the selected engine, files, and settings. Running both engines together produces one clean final image instead of duplicate or missing results, PixInsight queue stacking picks up your calibration masters, and the final stacked output is linked correctly even when PixInsight saves it in a nested folder. CosmicClarity Denoise and Sharpen now report when the tool is not installed instead of silently skipping that step, and the setup wizard summary shows which Siril tool was selected.
  • Improved Stability and presentation across long runs — a broad stability pass across scanning, stacking, plate solving, external-tool handoff, cancellation, and shutdown, so background jobs start, report progress, cancel, and close predictably instead of appearing stuck or showing the wrong status. Multi-panel mosaics captured in a single folder are detected automatically while single-session folders are no longer split into false panels, plate-solve previews draw the WCS grid and distortion view correctly right after solving, and the Backfocus Telescope Manager gains updated 3D renders throughout.

1.0 Release Candidate 1

June 28, 2026

The first release candidate, opening the final validation phase before the full 1.0 launch — and the biggest step yet: a plate solver built into AstroIndexer, a QA-driven stacking workflow that drives Siril and PixInsight, an object detector, iOS and Android companion apps, the Inspect Loupe, and an expanded Backfocus Manager.

New Features

  • New A plate solver, an Inspect Loupe and an Object Detector, built in — AstroIndexer's own plate solver detects the star field, computes the WCS solution and stores native SIP distortion coefficients right alongside your frame, at 18.6% lower median solve time than ASTAP in the latest raw-light benchmark and with no external solver to install. The Inspect Loupe pixel-peeps any sub at 1:1 with live FWHM, HFR, PSF and histogram readouts, and the Object Detector annotates every catalogued object in a solved frame — galaxies, clusters and more — cross-matched against LEDA, SDSS, MCG and 2MASX with a keep / reject findings table.
  • New One-click stacking, mobile companions and filter lifecycle tools — AstroIndexer sorts your subs by QA score, balances your filters and hands the keepers straight to a stacker: PixInsight AutoIntegrate with RC Astro tool detection, or Siril via AstroIndexer's own workflow scripts, each with ready-made sequences for OSC, broadband and narrowband. Alongside it, iOS and Android companion apps for your catalogue on the go, Image Overlay Export for share-ready images, filter lifecycle tools that keep filter-aware quality and stacking accurate over time, and an expanded Backfocus Manager with an under / within / over tolerance band.

Beta 6

June 15, 2026

Dial in your imaging train — Beta 6 introduces the Backfocus Manager in the Equipment tab, so you can plan and verify sensor backfocus spacing before you ever head out under the stars.

New Features

  • New Backfocus Manager (Equipment) — a visual workbench for your imaging train. Build your setup from a vendor inventory of cameras, off-axis guiders, and filter wheels, see the spacing drawn to scale, and get the spacer combination needed to hit each sensor's required backfocus distance.

v22.5

March 2026

Major performance release — Imaging Intelligence features, PixInsight AutoIntegrate stacking with RC Astro tool detection, tier-driven stacking advisor, and native XISF support.

New Features

  • New PixInsight AutoIntegrate stacking — one-click auto-stack directly from Autopilot with RC Astro tool detection (BlurXTerminator, StarXTerminator, NoiseXTerminator) and built-in default settings
  • New Tier-driven Stacking Advisor — 3 presets (Default Stack, Deep Stack, Sharp Focus) with filter balancing for canonical compositions (LRGB, SHO, HOO, RGB)
  • New Performance Insights — hero insights with equipment rankings, correlation-based analysis, session intelligence, and filter-aware recommendations in the QA tab
  • New Gallery Archive Overview — sidebar with Quick Archive Stats, Sky Coverage, Equipment Usage, Best Nights, Most Revisited Targets, and Seasonal Seeing
  • New Native XISF support — built-in XISF encoder/decoder with no external dependencies
  • New Companion Monitor v2.1 — full dashboard refresh with app launcher and real-time QA pipeline monitoring
  • New QE Curve filter overlays — visualize filter bandpass overlays on sensor quantum efficiency curves with SPCC sensor QE import
  • New Expanded frame type classification — 70+ IMAGETYP variants including SNAPSHOT, FOCUS, PREVIEW, STD, and all major software conventions
